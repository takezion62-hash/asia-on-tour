# 第4段階：予選突破判定の改善
新規早期承認は、登録済み公式地域別通過順位を越える成熟済み連続順位表、通過圏内の本人行の一意な一致、本人Epic IDと決定的候補ID、公式イベント・開催日・地域・予選ラウンド、試合数、既存の重複防止を要求する。通常の部分取得と公式境界を越えた打ち切り完了を区別し、同じ証拠判定を使う。終了後4時間未経過、境界未超過、取得エラー、別開催枠、候補重複は新規経路で拒否。
対象は既存承認ルートのPlayStation BR/ZB、Performance Evaluation、歴史的Solo/S30 Squads Victory Cup（モバイル含む）。旧NAをNAC/NAWへ推測変換せず、登録された個別NAC枠だけを利用。Duo Round1およびS43 Squadsの既存ライブ承認を維持し、保存済み候補再審査に厳密な通過境界の経路を追加する。Console Duos専用の既存予選経路も維持。
新規経路は突破圏内のみ。予選賞金は$0、決勝賞金は推測しない。既存の完全取得・手動承認・参加確認・VR/順位賞金の経路を維持し、既掲載戦績の一括再審査は第5段階、未登録の公式規則の補完は第6段階。API予算・順位表取得停止条件・実データは変更しない。
