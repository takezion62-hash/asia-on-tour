# S43 Squads Victory Cup 専用自動承認

既存の公式ルール数値は変更しない。専用フラグ autoApproveSquads を新着・過去の両方に追加。S43 BR Event 1/2 等の公式カレンダー登録枠のみ、4人全員の既知Epic IDと元候補ハッシュを再照合する。旧候補に元ID配列がない場合、各選手のIDが一意かつ元ハッシュと一致する場合のみ承認。混成チームの一部掲載・同順位・同一メンバー重複は自動追加しない。

予選8試合まで、EU300/NAC200/その他海外120位以内を突破、圏外は予選順位として賞金$0。成熟済み連続順位表の観測範囲も利用。新しい歴史スキャンでは圏外の順位も取得対象とするが過去の打ち切り済みチェックポイントを強制再走査しない。決勝は完全順位表、3試合まで、地域の進出上限内の順位、100pt/VR一致、1VR各$50・4人合計$200。0VRも$0。実際の受給資格・支払完了は未確認。

保存済み再審査でも同じ承認を使用（既存のオフライン完全順位表条件と保存公式カレンダーを維持）。現行日程と実際の開催時刻の一致を必須とするため日程不足時は保留。安全統合時も最新mainの混成チーム・同順位を再照合し、競合は元候補を保持。汎用ソロ承認の拒否は維持。既掲載戦績や賞金は変更しない。追加API予算なし。
