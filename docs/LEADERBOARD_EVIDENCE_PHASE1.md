# 順位表証拠判定の共通化（第1段階）
既存 scripts/verified-partial-page.cjs を共通の読み取り専用証拠レイヤーとする。順位表が全取得済み (full)、部分取得 (partial)、途中打ち切り完了フラグ付き (cutoff-complete)、証拠不備 (invalid) かを区別。cutoff-complete は公式条件を満たしたこと自体の証明ではない。連続ページ数・順位順序・対象順位・終了4時間経過・取得日時・エラー/再試行を共通化。順位境界の判定は呼び出し側が公式地域別の条件を明示することが必要。候補の一致・必要なら一意性・Epic ID保持を検査。本人ID・開催枠・賞金表・配分・ラウンド・重複の認定は引き続き各大会専用承認器の責務。
既存の部分ページ承認・保存済み候補の完全順位表判定・S43 SquadsとS35/S37 Console Duos予選・NVIDIA正の賞金・既掲載参加確認再審査を接続する。既存 PlayStation 予選再審査の境界 >= は互換性のため保持、NVIDIA/旧コンソール打ち切り判定は >。既存スナップショット/監査証拠を書き換えない。無効なメタデータは保留する。既存の全取得のみの大会の承認条件を緩和しない。大会規則・戦績・賞金額・API予算・取得打ち切り・スケジュールの設定変更なし。第2段階以降に順位賞金、VR賞金、予選ごとの明示的な導入を行う。
