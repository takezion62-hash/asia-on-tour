# 確認待ち候補の完全一致自動解消

2026-11-24 時点の重複疑い9件は S43 Trios Cash Cup の既掲載戦績との照合候補。個別IDをハードコードせず、現行の順位別賞金 Cash Cup 決勝の承認アダプターを再利用する。候補が持つ null 賞金は0とみなさず、既存公式承認条件に合格した場合のみ計算結果を既掲載の個人・チーム賞金と比較する。

必要条件：本人確認済みの全チームEpic IDと正規名が双方に保存済み、同一大会・地域・開催日・公式URL・決勝ラウンド、順位・ポイント・キル・VR・試合数完全一致、既掲載戦績が一意、公式カレンダー一意、成熟済み完全順位表・保存候補一致、他候補や承認履歴に矛盾なし。明示保留IDは除外。既掲載1件を除いた読み取り専用スナップショットで既存 Cash Cup 承認を再実行し、公式個人・チーム賞金が完全一致した場合だけ履歴に already-published を追記する。公開戦績・賞金・更新ログ・承認済み掲載台帳・元スキャンは変更しない。

`npm run review:duplicates` は読み取り専用診断。過去大会の既存安全統合ワークフロー（mainを再取得し競合時は再評価）で --apply を実行、両確認待ちキューを整理し history-sync-reviewed.json に監査根拠を保存。新着・過去の同一候補IDは1回だけ解消。未確認報酬、異なる順位、部分順位表、本人ID不足、他シリーズ、予選・参加確認のみ・コスメ・VR賞金大会は自動解消対象外のまま。対象9件の実際の解消数は本番の最新データによる。追加API不要。
