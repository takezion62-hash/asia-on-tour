# 既掲載参加確認の予選突破・賞金再照合
対象: 既存の attendance-only 承認台帳にあるS43 PlayStation Cup BR/ZB、S43 Trios Cash Cup、S39 NVIDIA Cupで、登録済み公式地域別条件から予選突破または正の賞金が期待される成績。公式開催ID、本人Epic IDと決定的候補ID、元スコア、成熟済み連続順位表、公式アーカイブ、既存専用承認器、重複を再検証。PlayStation予選のみ既存スキャナの公式通過枠を越えた完了済みprefixを許可。賞金は原則全ページ完了が必要。ただしS39 NVIDIAの正の現金賞金のみ、終了後4時間を経過した連続順位表が地域別公式賞金圏の最終順位を越え、元の本人Epic IDと候補が一致した場合は未完了prefixを許可する。全ページ未取得を記録し、他大会・賞金圏外・GPU/コスメ報酬には拡張しない。通常調査と保存済み再審査でも同じ専用判定を使用する。未確認は保持。元承認台帳は不変、戦績IDも維持し、別のbefore/after/証拠監査台帳で後から再検証。既存recent安全統合後の再分類ジョブに接続し、追加APIなし。S43 ZB予選12件、S43 NAW Trio 9位チーム$300、S39 NVIDIA 3件（$400）は初回調査の候補であり、実際の更新件数は厳密な再検証後に確定する。未登録公式ルール・別の固定承認ポリシーは対象外。
