# Console Duos Victory Cup 専用自動承認

S35 (2025-05)・S37 (2025-08以降) の登録済み公式規則に限定。S36は決勝の正確な賞金単価が未登録のため旧予選承認のみ維持。S42 Reloadなど別大会の承認条件は変更しない。

autoApproveConsoleDuos を新着・過去に明示設定。専用方式が有効な場合はS35/S37を汎用ソロ・旧デュオ・固定候補専用承認に渡さず、本人Epic ID2名、元候補ハッシュ、保存公式カレンダーの完全一致、成熟済み連続順位表、既掲載・混成チームとの重複を必須とする。予選は最大7試合、EU/NAC500組・その他250組。圏外は予選順位として$0。歴史上の通過枠打ち切り済みチェックポイントも、実際に見た順位・成熟済み連続ページの証拠がある場合のみ利用する。API問い合わせ前の再審査にも対応。

決勝は完全順位表・最大3試合・100pt/VRと地域の決勝人数上限・本人ID・公式規則を照合し、1VR個人$100/チーム$200、0VRは$0。未確定の賞金や受給資格を推測しない。最新mainへの安全統合時も混成チームや同順位の競合を保留。既掲載戦績・賞金・ルールJSONは変更しない。追加API予算なし。
