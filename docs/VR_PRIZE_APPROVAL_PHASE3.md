# VR賞金型大会の早期承認（第3段階）
第2段階のPR #233を前提とする。本人の決勝VR数に基づく賞金は下位の未取得順位に依存しないため、登録済みVR単価、成熟済み連続順位表、対象行の一意な完全一致、公式決勝ラウンド、本人Epic ID・決定的候補ID、公式試合数、順位上限、既存の重複防止を確認できる場合のみ早期承認する。
対象は既存のverifiedポリシーが対応する正のVR賞金付きソロ（S32/S41/S42の登録済み地域・モバイル含む）、S43 Performance Evaluation EU/NAC、S35/S37 Console Duos、S43 Squads。チームでは全員の本人IDと100pt/VRの整合性を確認。Soloでは公式ルールに得点式の登録がない場合に100pt/VRを推測しない。正の賞金には正の得点と公式試合数を要求する。過去の0VR承認ルートと完全取得ルートを維持。未登録の賞金額、S36等の予選専用ルール、他大会、既掲載戦績の一括再分類、予選判定の変更は対象外。
保存済み候補の再審査にも各専用承認器を利用し、Performance決勝の確定レコードを対象に含める。取得済みページ数と未取得の事実を注記し、支払完了を主張しない。API予算・取得停止条件を変えない。
