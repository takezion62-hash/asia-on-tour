# ASIA ON TOUR — 自動収集効率・スカウティングレポート（2026-11-08）

## 自動収集の効率改善
- `scripts/scan-efficiency.cjs` は、保存済みページ位置 `nextPage` と総ページ数 `totalPages` から「1開催枠あたりの今回の取得上限内で完了できる」未完了枠を最大2件抽出する。判定できないページ数は推測せず対象外。
- **直近調査**：期限到来の再試行を最優先し、その後に少ないページ数で完了できる開催枠を優先する。Victory Cup / その他のシリーズの両枠を維持する。
- **過去調査**：期限到来の再試行と年度・シリーズの調査枠を確保した後、最大2件の「完了目前」枠を選択する。既存の地域分散・シリーズ分散、2026年直近分、手動の優先条件は維持する。
- **参加アーカイブ**：直近枠、既に調査中の枠、2024年・2025年の調査枠を確保した後に、完了可能な開催枠を最大1件選ぶ。
- 結果JSON、賞金、名鑑、大会定義、公式通過枠の判定条件は変更しない。取得失敗・不正ページ・ID競合の安全な保留、再試行時刻、ページ予算の上限、既存チェックポイントは維持する。
- 未調査の全件を短時間で完了できるという意味ではない。収集APIの速度・制限、未登録イベント、Epic ID未照合、資格ルール未登録は引き続き制約となる。

## スカウティングレポート
- 選手プロフィールの既存「プレイスタイル分析」内に、折りたたみ式の **スカウティングレポート** を追加。
- 現在選択した期間・地域・大会シリーズ・モード・チーム形式に対して、以下を実測値で表示：
  - キル / 試合、VR / 試合（試合数を確認できた記録のみ）
  - キル / 試合の開催枠間の加重標準偏差（5開催枠・30試合以上の確認記録がある場合のみ）
  - 掲載された遠征開催枠数・地域数・決勝記録
  - 直近5枠と前5枠のキル効率・VR率の差（両期間に15試合以上の実測が必要）
  - 同条件で比較可能な20名以上が揃った場合の既存プレイスタイル分類
- **評価可能** は5開催枠・30試合以上、**暫定** は3開催枠・15試合以上。データ不足では強さを断定しない。0VRとVR未確認は区別する。
- デュオ/トリオ/スクワッドのキルやVRはチーム合計。個人キル・対面勝率・Ping・IGL/フラッガー・大会難易度・予測には読み替えない。
- 出典リンク、重複・ID矛盾の除外、本人確認済み出場アーカイブとの重複抑止は既存のプレイスタイル分析を再利用。賞金・AOT PR・称号・元データを書き換えない。
