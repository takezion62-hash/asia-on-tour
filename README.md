# asia-on-tour
ASIA勢のFortnite海外大会戦績まとめ

掲載済みの戦績を検索・閲覧するための閲覧専用サイトです。
地域・大会区分・賞金獲得の絞り込み、並び替え、選手別の戦績表示、CSV出力に対応しています。
戦績の追加・削除、JSONの読み込み、ブラウザ内への保存は行いません。
以前ブラウザに保存した独自の記録は表示・集計に使用せず、その保存データ自体は変更しません。

`index.html` をブラウザで開くと利用できます。掲載内容の更新はこのファイルのデータを編集して行います。

回帰テストは Node.js で `node --test tests/read-only.test.cjs` を実行してください。
